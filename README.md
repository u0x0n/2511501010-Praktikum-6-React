# TodoList React CRUD

Aplikasi TodoList dengan React 19 dan Bootstrap.

## Fitur
- Tambah, edit, dan hapus task (CRUD)
- Badge warna pada Priority (High merah, Medium kuning, Low hijau)
- Badge Status (To Do, In Progress, Done)
- Pencarian task
- Data tersimpan di localStorage
